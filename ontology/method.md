# Method

`Method` описывает алгоритм ускорения. Его сущность не привязана к конкретному
запуску, поэтому один метод можно сопоставлять с несколькими экспериментами и
сравнивать при разных гиперпараметрах и на разном оборудовании.

## Поля

| Поле | Тип | Обязательное | Назначение |
|---|---|---:|---|
| `method_id` | `string` | да | Уникальный идентификатор метода |
| `description` | `string` | да | Содержательное описание метода |

## Пример

```yaml
method_id: quietprune
description: >-
  Метод сжатия последовательности визуальных токенов QuietPrune.
```
